What it is

  • Twenty-minute runs, then an endless mode with no finish line
  • 16 weapons, each with an evolution to discover
  • Four survivors, four arenas, a different hand every run
  • One thumb, portrait, never rotates
  • Fully offline — no connection required
  • No forced ads, no energy timers, no paywalled progression
